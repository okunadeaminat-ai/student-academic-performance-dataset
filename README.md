Student Academic Performance Dataset

Project Overview

This project was developed using C++ for the CUL-CYB 371 Data Mining and Data Warehousing assignment.

The program creates a fictional student dataset containing academic information for 20 students across four departments.

Dataset Information

The dataset contains the following fields:

1. Student ID
2. Department
3. Level
4. Attendance Percentage
5. Average Examination Score

Programming Language

C++

Tools Used

* Visual Studio Code
* GCC C++ Compiler (MinGW64)
* CSV file format

How the Program Works

The program uses a C++ structure to organise student information and a vector to store multiple student records.

It then writes the records into a CSV file named students.csv.

The generated CSV file can be opened with Microsoft Excel or other spreadsheet applications.

How to Run the Program

Compile the source code:

g++ main.cpp -o student_dataset.exe

Run the program:

./student_dataset.exe

Project Files

* main.cpp – C++ source code.
* students.csv – Generated fictional student dataset.
* README.md – Project documentation.

Note

All student records in this project are fictional and were created for academic purposes.
